# dbplex

Local copies of your production databases on your Mac, never written back.

This repository holds dbplex's releases and its issue tracker. The app's source code is not here.

## Download

Get dbplex from [dbplex.app](https://dbplex.app), or the DMG from [Releases](https://github.com/DBplex/dbplex/releases/latest). It runs on Macs with Apple silicon.

Once installed, dbplex tells you when a new version is out and updates itself when you say so. Your copies keep running while it does.

## Report a problem

In dbplex, open Settings, then Help, and choose Report a problem. The app writes a report for you to read before anything leaves your Mac: the names of your databases and hosts are already replaced. Then post it here as a [new issue](https://github.com/DBplex/dbplex/issues/new).

Issues are public, so read what you wrote yourself before you post it. dbplex never uploads a report on its own.
